Claude Design's Handoff button gives you a zip. Drop it here, choose the pages worth keeping, and they stay on the shelf above — so coming back to one costs a tap instead of another upload. Every artboard opens in a real browser, so the design system, the animations and the pixel fonts load exactly as they do on claude.ai.

For a video, ask it to find the loop: it plays the slide, catches the moment the picture starts repeating, and cuts there — so the clip loops without a jump. Tell it roughly how long that loop might be and it plays only as much of the slide as that takes. Any slide, moving or not, can also come back as a PNG re-drawn at up to four times its size.

If something is off

No loop was found

Some slides only repeat after a minute or more. Raise the seconds beside Find the loop and look again, or type the length yourself — it is usually written in the design source as DURATION.

It says there is not enough memory

Every doubling of the size costs about four times the memory, and a video renders in several browsers at once. Drop to 1×, lower the fps, or press Close the browsers above and try again.

It says the page never mounted

A raw .dc.html loads React from unpkg.com, so this box needs to be online. If it is, try the copy inside the bundle's export/ folder — that one is self-contained.

Pasting a claude.ai link

Those pages need your login, so they will not load. Public or self-hosted URLs work; for Claude Design, use the zip.

Where the files live

On this machine, under your app-data folder. Nothing is uploaded anywhere.
